# Customer Segmentation Using PCA and K-Means Clustering

## Overview

This project was completed as part of the Decode Labs Data Science Internship.

The objective was to perform customer segmentation using unsupervised machine learning techniques. PCA was used for dimensionality reduction and K-Means clustering was applied to identify distinct customer groups.

---

## Dataset

Dataset: Customer Personality Analysis Dataset

The dataset contains customer demographics, purchasing behavior, and spending patterns used for segmentation analysis.

---

## Project Workflow

### 1. Data Exploration
- Dataset inspection
- Feature analysis
- Missing value detection

### 2. Data Cleaning
- Removed missing values
- Created new analytical features

### 3. Feature Engineering
- Age calculation
- Total Spending calculation

### 4. Data Standardization
- StandardScaler applied to numerical features

### 5. Principal Component Analysis (PCA)
- Reduced dimensionality
- Retained 95% of data variance

### 6. Elbow Method
- Determined optimal number of clusters

### 7. Silhouette Score Analysis
- Evaluated cluster quality

### 8. K-Means Clustering
- Segmented customers into meaningful groups

### 9. Data Visualization
- PCA-based cluster visualization
- Scatter plots for cluster interpretation

### 10. Customer Personas
Created business-oriented customer segments such as:
- High Value Customers
- Budget Shoppers
- Young Moderate Buyers
- Premium Loyal Customers
